Gerät einrichten

Diesen einmaligen Token innerhalb von 15 Minuten im Root-Installer eingeben. Er wird nur jetzt angezeigt. Nicht in Logs oder Tickets kopieren.

  1. Installer herunterladen und auf das Zielgerät kopieren.
  2. Im Download-Ordner den folgenden Befehl ausführen (Windows: PowerShell als Administrator). Private Releases benötigen GH_TOKEN mit Leserechten im Terminal.
  3. Der Installer lädt das passende GitHub-Release-Paket, prüft es und startet die Einrichtung.
  4. Den Token erst in der verdeckten Terminal-Abfrage eingeben.

Bei eigener Zertifizierungsstelle zusätzlich --ca-file /pfad/ca.pem angeben. Anmeldung nur für freigegebene Konten; Windows benötigt die zusätzliche Anmeldekomponente. Bestehende Geräte: Installer erneut starten, kein neuer Token nötig.

Automatisierung

Linux- und Windows-Geräte holen Jobs ab. Startzeit in lokaler Browserzeit; leere Startzeit bedeutet sofort.

Neuen Job anlegen

Eigene Skripte laufen mit vollständigen Root-/SYSTEM-Rechten auf den zugewiesenen Geräten. Nur vertrauenswürdigen Code verwenden; keine Passwörter oder Schlüssel im Skript hinterlegen.

Die Interpreter-Auswahl gilt; die Shebang-Zeile wählt keinen anderen Interpreter. Änderungen wirken nur auf neu eingereihte Läufe.

Paketupdates führen apt update und apt upgrade aus. Bestehende Konfigurationen bleiben erhalten; ein Neustart wird nicht automatisch ausgelöst. Wiederholungen ab 5 Minuten bis 10 Jahre. Ein Jahr entspricht 365 Tagen.
