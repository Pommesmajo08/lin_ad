# Linad v0.2.7

HTTP-Verbindungen sind jetzt standardmäßig in allen Linad-Programmen und Installern erlaubt. CLI, GUI, Linux-Provisioner und Windows-Agent benötigen weder `--allow-http` noch `-AllowHttp`; ältere Konfigurationen funktionieren ebenfalls ohne erneutes Enrollment. Die bisherigen Optionen bleiben kompatibel.

- Die GUI verbindet HTTP-Server direkt; die zusätzliche Freigabe-Checkbox entfällt.
- Generierte Installationsbefehle benötigen keine HTTP-Sonderoption.
- HTTPS sowie die Prüfung von Zertifikaten und Hostnamen bleiben verfügbar.

HTTP überträgt Anmeldedaten und Geräteschlüssel unverschlüsselt. GitHub-Downloads verwenden weiterhin HTTPS und Paket-Prüfsummen. Die Server-Portbindung bleibt unverändert. Für Netzwerkzugriff kann die bestehende Docker-Portfreigabe manuell angepasst werden; siehe Installationsanleitung.

Die optionale Windows-Anmeldung bleibt eine Vorschau; vor produktivem Einsatz Anmeldung, Entsperren und Wiederherstellung auf einer Test-VM prüfen.
